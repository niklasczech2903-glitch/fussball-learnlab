# LearnLab – Fußballanalyse

Eigenständige PWA, getrennt vom PnL Tracker. Enthält 6 Kategorien mit 18 Lektionen, 8 Quizfragen, Quoten-/EV-Rechner, Poisson-Rechner, Notizen, Fortschritt und JSON-Backup. Daten werden lokal gespeichert.

## Installation über GitHub Pages
1. Neues öffentliches Repository z. B. `fussball-learnlab` anlegen. **Nicht** die Dateien deines bestehenden PnL-Trackers überschreiben.
2. Alle Dateien aus diesem Paket in das Hauptverzeichnis hochladen. Den Ordner `icons` beibehalten.
3. Unter Settings → Pages → Deploy from a branch → main → /(root) speichern.
4. Nach Veröffentlichung die URL `https://BENUTZERNAME.github.io/fussball-learnlab/` in Safari öffnen.
5. Teilen → Zum Home-Bildschirm → Als Web-App öffnen → Hinzufügen.
6. Nach dem ersten vollständigen Laden ist die App offline verfügbar.

**Wichtig:** Der Browser-Speicher kann gelöscht werden. Unter Profil regelmäßig ein JSON-Backup exportieren. Keine Gewinngarantie, keine Wettabgabe.
